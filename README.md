# FillThisPDF

**Got a PDF to fill? Drop it here.**

The official repository for **fillthispdf.othrys.be** — a lightweight, privacy-first PDF form completion tool with optional, genuine AI assistance.

## Product in one sentence

Upload a PDF, add information to the form, review what changed, and download the completed PDF **for free**, without creating an account.

## Status

**Foundation / T3 Code handoff.** The implementation is not complete. Do not describe the website or any AI feature as working until tested.

## Principles

- One useful page; one task; fast on mobile.
- Manual PDF editing and downloads must work even with AI disabled.
- No login, forced subscription, watermark or backend document storage.
- Browser-local PDF processing by default.
- AI is an opt-in enhancement; never quietly send people's documents to a model provider.
- No demo pretending to work, no placeholder action that claims completion.
- Avoid dependencies on OTHRYS platform code. Standalone repo and deployment.
